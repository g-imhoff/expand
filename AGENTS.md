# Agent Instructions

## Source Comments

Agents must not add source-code comments. The project owner is the only person who adds comments.

When modifying existing code:
- Remove agent-authored explanatory comments when touching nearby code.
- Prefer clearer names, smaller files, and focused functions over comments.
- Do not add inline rationale comments, section comments, or “why” comments in source files unless the project owner explicitly requests a specific comment.
